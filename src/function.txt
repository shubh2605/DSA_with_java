stack memory and heap---------------
-Fxn and their local variable are created in stack memory
-stack contains the stack frames made by fxn which contains its variable
-object,refrence ,runtime data are stored in heap momory

-stack memory is faster than heap memory

function overloading----------------
two or more fxn of same name with diff no of parameters,if no of parameters will be same then the return type will be different.

function overriding---------------
When a child class inherits a method from a parent class, it override that method to change its behavior.
static and final method cant be override

class A{
    public  int add(int a,int b){
        return a+b;
    }
}
class B extends A{
    @override
    public  int add(int a,int b){
        return a*b;
    }
}
